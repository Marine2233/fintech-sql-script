## Учебный репозиторий, основанный на **JDK 21+** с использованием технологий **`ExecutorService` (виртуальные потоки)** и **`CompletableFuture`**, предназначенный для отработки базовых навыков работы с SQL в средах **PostgreSQL** и **DBeaver**.


#### В проекте в папке fintech-sql-script/script- содержатся 4 файла:
        step1.sql- создает БД
        client.sql- создает таблицу клиентов заполняет данными и исполняет скрипты
        account.sql- создает таблицу банковских счетов заполняет данными и исполняет скрипты
        script/05_advanced_select.sql- скрипты выборок с разными простыми операторами


#### В папке fintech-sql-script\src\main\java\sql- 
    описан основной класс записи в файлы инструкций по средствам статического класса Files из пакета NIO


#### В папке fintech-sql-script\src\main\java - 
    точка запуска программы main- в методе применен ExecutorService(виртуальные потоки)-
    для наименьшего расхода ресурсов, CompletableFeatures- для запуска задач записи в файлы параллельно
